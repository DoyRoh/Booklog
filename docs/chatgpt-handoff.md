# 책숲 — 챗지피티에 넘기는 요약 (컨셉 · 지금까지 만든 것 · 그림 스타일)

> 이 문서를 통째로 챗지피티 대화 맨 처음에 붙여 넣고, 아래 "같이 올릴 그림"을 첨부한 뒤 요청을 시작하세요.
> 이 문서만으로 앱이 무엇인지, 어떤 화면과 규칙이 있는지, 그림은 어떤 결인지 다 알 수 있게 썼습니다.

---

## 1. 한 줄 소개

**책숲**은 아이의 독서를 부모와 "숲지기"(선생님·가족·도서관·인플루언서 등 그룹을 운영하는 사람)가 함께 기록하고 넓혀 가는 어린이 독서 앱입니다. 폰 브라우저에서 쓰는 웹앱(PWA)이고, 홈 화면에 추가해 앱처럼 씁니다.

**세계관 한 줄**: 끝없이 넓은 책숲, 정답 없는 길을 자유롭게 헤매며 탐험하고 발견하고 즐기는 여정. 아이는 이 숲의 여행자이고, 부모·숲지기는 함께 걷는 조력자입니다.

**핵심 목표**: 부모가 책 한 권을 기록하는 데 30초 이내.

**절대 하지 않는 것**: SNS·댓글·친구·채팅·결제·광고, AI 독후감 자동 작성, 아이들끼리 비교·순위, 과도한 게임화.

---

## 2. 사용자와 프로필

계정 하나에 프로필이 여럿입니다.
- **아이 프로필**(부모가 관리): 아이마다 이름·생일·아바타(토끼/강아지/고양이 중 하나). 아이가 여럿이면 전환.
- **숲지기 프로필**: 그룹을 만들어 운영하는 쪽. 선생님도, 가족도, 도서관도, 크리에이터도 숲지기입니다. 숲지기 이름 하나 + 그룹 여러 개(예: "7살 추천도서", "6살 추천도서").
- 아이 프로필 ↔ 숲지기 프로필 전환은 상단의 얼굴/이름을 눌러 "프로필 · 설정"에서.

그룹은 두 종류: **승인제**(학급처럼 초대 코드로 참가, 숲지기가 승인)와 **공개**(도서관·인플루언서처럼 누구나 팔로우).

## 3. 화면 구조

### 부모·아이가 보는 화면 (하단 탭 4개: 오늘 · 책장 · 숲길 · 숙제)
- **오늘**: 손글씨 인사말 → 요약 카드("우리 숲" 나무 띠 + 읽은 책 N권 + 오늘/이번 주/이번 달/그룹 4칸 통계) → 큰 "+ 책 기록하기" 버튼 → 오늘의 숙제 요약 → 최근 기록.
- **책장**: 나무 선반 위에 표지 3권씩. 보기 방식 전면/책등/목록, 검색, 그룹·상태·정렬 드롭다운, 독서 리포트 내보내기(인쇄).
- **숲길**: 그룹 타일(앱 아이콘 같은 둥근 네모, 새 책 수 배지) → 그 그룹의 추천도서를 서점 앱처럼 표지로 둘러보고 **책갈피**(내 책장에 꽂기)·**체크**(읽었어요)로 바로 표시.
- **숙제**: 그룹 타일 → 이번 주 숙제 / 다가오는 숙제 / 지난 숙제. 숙제마다 읽을 책 목록(체크로 읽음 표시), 질문 미션(답 쓰기), 낭독 미션(녹음).
- **기록 남기기**(한 화면): 제목 입력 = 검색(카카오 책 검색 자동완성) 또는 바코드/ISBN → 지금 상태(읽고 싶어요/읽는 중/다 읽었어요) → 언제 읽었어(오늘/어제/그제) → 재미있었어(스티커 5종) → 저장. "더 남기기"를 펼치면 책장 나누기·오늘의 질문/메모·사진·아이 목소리 녹음.
- **우리 숲**(상단 오른쪽 나무 아이콘): 딴 배지가 곧 숲이 되는 화면 — 권수 배지 하나 = 나무 한 그루, 나머지 배지는 별·등불·새·발자국 장식. 아래는 배지 목록(총 65개, 숲 이름: 씨앗 하나 → 새싹 다섯 → 작은 숲 → … → 천 그루 숲).
- **프로필 · 설정**: 아이/숲지기 전환 타일, 아이 추가, 책장 공유(다른 보호자 초대 코드), 책장 나누기(6살 책장/7살 책장 같은 이름표), 그룹 찾기·참가.

### 숲지기가 보는 화면 (하단 탭 4개: 대시보드 · 아이들 · 추천도서 · 숙제)
- **대시보드**: 그룹별 그룹원 수·승인 대기·숙제 진행(N/M명).
- **아이들**: 그룹별 아이 목록(추천도서 X/Y권 읽음 · 숙제 A/B 완료) → 아이별 상세.
- **추천도서**: 그룹별 최근 10권 미리보기 → "관리"에서 전체 목록·책 추가(검색/바코드/ISBN/직접 입력, 분야 칩)·선택 삭제.
- **숙제**: 그룹별 숙제 목록(낸 날 / ~마감, 미션 칩, N/M명 완료) → "+ 숙제 만들기": 제목, 안내, 언제까지(하나만), 읽을 책(직접 찾아 넣기 또는 추천도서에서 고르기, 목표 쪽수), 질문/낭독 미션.
- 그룹 상세: 이름·유형·소개 고치기, 초대 코드, 가입 승인, 그룹 삭제/나가기.

### 첫 화면들
로그인(밤 숲에서 동물들이 책 안고 고개 내미는 그림), 회원가입(낮 숲길 행렬), 온보딩(아이 & 부모 / 숲지기 선택 → 약관 → 아이 이름·생일·아바타), 앱 켤 때 스플래시(세로 밤 숲 그림 + 명조체 한 문장 + "책숲" 로고, 2초).

## 4. 디자인 시스템 (반드시 지킬 것)

**색 (CSS 토큰)**
| 이름 | 값 | 쓰임 |
|---|---|---|
| paper | `#EAF0E5` | 앱 배경(세이지 그린 종이). 흰 배경 안 씀 |
| card | `#FFFFFF` | 카드 |
| ink | `#26362B` | 본문 글자(짙은 숲그림자) |
| ink-2 | `#5C6B5F` | 보조 글자 |
| rule | `#D9E3D3` | 테두리·선 |
| point | `#2FA84F` | 주요 버튼·선택·진행 |
| point-deep | `#1B5E3A` | 눌림·진한 강조 |
| lantern | `#E8A33D` | 곰의 등불 호박색 — "지금 주목" 배지 |
| berry | `#D94A32` | 아주 드물게(기록하기 버튼, 알림 숫자) |

**글꼴**: 제목·버튼·숫자는 고딕(Gowun Dodum), 인사말·짧은 감성 문구만 손글씨(Gamja Flower), 스플래시 문장은 명조(Gowun Batang). 본문은 시스템 글꼴. 전체 글자 크기는 기본보다 12.5% 큼(아이 손가락·눈 기준).

**형태**: 카드 모서리 22px, 버튼 14px, 칩은 알약형. 좌우 여백 20px, 카드 안쪽 24px, 8px 단위 간격. 제목과 내용은 항상 **한 카드 안에**(제목만 배경에 띄우지 않음). 목록은 카드 하나 안에 얇은 구분선. 하단 탭은 화면 가운데 떠 있는 둥근 알약 바(아래로 스크롤하면 숨고 올리면 나타남).

**아이콘**: 이모지·AI 클립아트 금지. 선(stroke) 아이콘만. 캐릭터·장면은 전부 오리지널 일러스트.

## 5. 캐릭터와 일러스트 (3D로 만들 때도 이 규칙 그대로)

**캐릭터 5종 (형태·색 고정)**
- **곰** = 숲지기. 까만 반달가슴곰(가슴에 흰 초승달), 연한 주둥이, **등불**을 들고 길을 비춤.
- **백로(하얀 새)** = 소식·편지. 흰 몸, 호박색 부리, 가는 검은 다리. 편지를 물고 날거나 앉아 있음.
- **토끼**(크림색, 연분홍 귀 안쪽) · **강아지**(꿀색 갈색, 늘어진 귀) · **고양이**(회청색, 뾰족 귀) = 아이 아바타. 아이가 고른 동물이 발자국 도장 모양이 됨.
- 모든 그림책은 **짙은 숲 초록 표지**.

**소품**: 켜진 등불·꺼진 등불, 발자국 도장 3종(토끼·강아지·고양이), 나무 4종(둥근·풍성한·전나무·연한), 별.

**장면 그림(이미 있음)**: 세로 밤 숲(스플래시), 밤 숲에서 책 읽는 동물들(로그인), 텐트 앞 캠프(온보딩), 낮 숲길 행렬(회원가입·404), 캐릭터·나무·별 패턴.

**그림 스타일 공통 문단(영어, 이미지 생성 프롬프트 맨 앞에 그대로 붙이기)**

```
Children's picture-book illustration in a simple naive crayon and oil-pastel style: hand-drawn, warm, gentle, quietly playful, like a child's favorite board book. Build everything from large flat chunky color shapes with visible broad crayon strokes, uneven waxy coverage and softly irregular edges. No outlines. Character rules: extremely simple and iconic, a rounded chunky silhouette, slightly imperfect handmade proportions, short stubby limbs, no neck. Face = two tiny black dot eyes, a small pale muzzle patch with a tiny black nose, and at most a tiny mouth line; no eyebrows, no blush, no sparkles, no teeth. Fixed character colors: moon bear = flat black fur with a small white crescent on the chest and a pale muzzle; white egret = flat white body, warm amber beak, thin dark legs; rabbit = cream with pale pink inner ears; dog = honey brown with floppy ears; cat = grey-blue with pointed ears; every picture book = deep forest green cover. Palette only: sage green (#EAF0E5), leaf green (#2FA84F), deep forest green (#1B5E3A), warm amber (#E8A33D), dark forest-shadow ink (#26362B), a tiny touch of berry red (#D94A32) only if needed, plus the fixed character colors above. Background: one perfectly flat uniform sage green (#EAF0E5) fill. No text, watermark, border, or frame. Not a sticker, not emoji or kawaii style, not glossy 3D, not vector clip-art.
```

**3D로 옮길 때 추가 지침(제안)**
- 위 캐릭터 시트를 첨부하고 "이 시트의 디자인을 그대로 3D로"라고 시작. 형태는 둥글고 뭉툭하게, 목 없음, 짧은 팔다리, 점 눈 두 개 — 2D 규칙 그대로.
- 재질은 **무광 클레이/펠트** 느낌(광택·반사·유리 질감 금지), 색은 위 팔레트와 캐릭터 고정색 그대로.
- 배경은 세이지 그린 단색, 바닥 그림자는 아주 옅게 하나만. 조명은 부드러운 한 방향(등불이 있으면 등불 쪽이 따뜻한 호박색).
- 출력은 정면 눈높이, 정사각, 여백 넉넉하게 — 앱 아이콘·프로필 얼굴로 잘라 쓸 수 있게.

## 6. 기술 (참고만)

Next.js(App Router) + TypeScript + Tailwind, Supabase(Postgres/Auth/Storage, 행 단위 보안 RLS), Vercel(서울 리전), 카카오 책 검색 API. 저장소: github.com/DoyRoh/Booklog. 코드 변경은 Claude Code로 하고 있고, 챗지피티에는 **기획·문구·그림·3D**를 맡길 예정.

## 8. 아직 없는 것 (챗지피티와 의논할 만한 주제)

- 배지마다 다른 그림(지금은 숲 조각 조합), 앱 아이콘 고도화, PWA 스플래시 기기별 이미지
- 3D 캐릭터·3D 숲 장면(우리 숲 화면), 굿즈·인쇄물(독서 리포트 꾸미기)
- 낱권 ISBN이 잘 잡히는 책 데이터원(알라딘 등), 오프라인 기록 큐잉, AI 요약(V2)
